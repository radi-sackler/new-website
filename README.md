# New Website

This project uses [Next.js](https://nextjs.org/) 14 with the App Router and Tailwind CSS.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Format the codebase:

```bash
npm run format
```

Pages available:

- `/` – landing page
- `/about`
- `/services`
- `/contact`
